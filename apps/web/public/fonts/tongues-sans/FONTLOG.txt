Tongues Sans font log
========================

Modified by the Tree of Tongues project: subset for the web and renamed, as required by the Reserved Font Name clause.

Original: Adobe Source Sans 3, release 3.052R.
Release page: https://github.com/adobe-fonts/source-sans/releases/tag/3.052R
Source archive: https://github.com/adobe-fonts/source-sans/releases/download/3.052R/VF-source-sans-3.052R.zip
Source archive sha256: d8e2ac355e06e6a0f0e0a0b1ac0c2451afa707584d7bb9d6b11ef9e4b749904c
Variable fonts used: VF/SourceSans3VF-Upright.ttf, VF/SourceSans3VF-Italic.ttf

Changes
- Subset into unicode-range slices (Latin, Latin Extended, Cyrillic, Greek, Vietnamese).
- Hinting removed; only English name records kept; web-useful OpenType features kept.
- Weight axis kept (200 to 900).
- Renamed to Tongues Sans. Name IDs 1, 3, 4, 6, 25 and all variable-font instance and
  STAT names no longer contain the Reserved Font Name. OS/2 vendor ID set to TOT.
- Copyright (ID 0), trademark (ID 7) and license (IDs 13 and 14) are unchanged from upstream.
