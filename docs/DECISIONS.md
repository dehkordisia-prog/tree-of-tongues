# Decisions log

Append only. One entry per decision: ID, date, decision, why, alternatives, revisit when.

- D-001 (2026-11-10). Glottocode is the primary key for every languoid. Why: stable, open (CC BY 4.0), covers families, languages and dialects. Alternatives: ISO 639-3 (no families or dialects), Wikidata QIDs (less curated classification). Revisit: never.
- D-002 (2026-11-10). Classification follows Glottolog by default. Traditional groupings, such as the Ethnologue-style tree in reference/infographic.png (for example Niger-Congo including Mande), appear only as a labeled alternative lens. Why: open data with documented criteria. Revisit: if users ask for more lenses.
- D-003 (2026-11-10). Every clip carries one of three badges: Recording, Reconstruction, Synthetic. Why: honesty about what users hear. Revisit: never.
- D-004 (2026-11-10). The English UI names the language "Persian"; "Farsi" exists only as a search alias. Owner decision.
- D-005 (2026-11-10). Speaker figures are never averaged. Each source is stored and shown with its year; disagreements appear as ranges. Why: estimates differ by method and date.
- D-006 (pending). Tree renderer: PixiJS or deck.gl, decided by the Phase 0 spike results (fps, memory, text quality). See D-021 for the provisional choice.
- D-007 (2026-11-10). Non-commercial forever: no ads, no paid tiers, no paid features, no sponsorship tied to content. The atlas is a contribution to people who love languages. Consequence: non-commercial (NC) sources such as the Speech Accent Archive, MMS-TTS and NC Glottography datasets are usable; any monetization would void them. Owner decision.
- D-008 (2026-11-10, confirmed by owner). Open by default, public on GitHub from day one: code under the MIT license; original writing under CC BY-SA 4.0; project recordings uploaded to Wikimedia Commons; data files keep each source's license. Why: others can learn from, reuse and improve the atlas.
- D-009 (2026-11-10). Third-party reference images (such as the 100 most-spoken languages chart) stay local in reference/ and are never committed, because the repository is public.
- D-010 (2026-11-10). Toolchain pins for Phase 0: React 19.3.1, React Router 8.5.1 (framework mode, `ssr: false` plus `prerender: true`), Vite 8.3.6, Tailwind 4.3.5, PixiJS 8.22.0, deck.gl 9.4.1, MapLibre 6.16.0, Vitest 5.1.0, Playwright 1.65.0; Python 3.12 with polars 2.1.0 and pycldf 2.1.1. Versions are exact pins in package.json and pyproject.toml. Why: reproducible builds. Revisit: at the start of each phase.
- D-011 (2026-11-10). TypeScript is pinned to 6.0.3, not 7.0. Why: typescript-eslint 8.72 supports TypeScript below 6.1 only. Alternatives: TypeScript 7 without type-aware linting. Revisit: when typescript-eslint supports 7.
- D-012 (2026-11-10). Supply-chain guard: pnpm's minimum release age check stays on, and we pin releases at least three days old instead of adding exclusions. Why: most malicious npm releases are caught within days. Revisit: never.
- D-013 (2026-11-10). Vector tiling (tippecanoe, PMTiles) is deferred to Phase 2 and will run in WSL or CI. Phase 0 maps read GeoJSON. Why: tippecanoe has no native Windows build, and Phase 0 data is small enough for GeoJSON. Revisit: Phase 2.
- D-014 (2026-11-10). Fonts are self-hosted and the app makes no third-party requests at runtime. Why: privacy (CLAUDE.md rule 11) and offline use. Revisit: never.
- D-015 (2026-11-10). Large font files stay out of git. The 97 Noto Sans SC slices (about 4.3 MB) are fetched before every dev and build run by scripts/fetch-fonts.mjs, which checks the npm tarball's sha512 and each file's sha256 against scripts/fonts.lock.json. Why: git history in a public repo is permanent, and Japanese, Korean and Traditional Chinese faces would add more. Alternatives: commit the files; drop Han until Phase 1. Owner decision.
- D-016 (2026-11-10). The heading and UI faces are our own web subsets of Adobe's official Source Serif 4 (4.005R) and Source Sans 3 (3.052R) releases, renamed Tongues Serif and Tongues Sans. Why: the OFL forbids a modified version, which a pre-made subset is, from keeping the Reserved Font Name "Source" (OFL FAQ 2.6 to 2.8), so the Fontsource slices could not ship. Alternatives: switch to Noto Serif and Noto Sans; serve Adobe's full files (first paint of several hundred KB); ask Adobe for permission. Owner decision. Revisit: never, unless Adobe changes the license.
- D-017 (2026-11-10, provisional: made overnight, awaiting owner confirmation). Themes use CSS `light-dark()` with a `data-theme` override and a saved manual choice. Browsers older than Chrome 123, Safari 17.5 and Firefox 120 fall back to default colors, which stay readable. Why: one set of tokens for both themes, no JavaScript on the critical path. Alternatives: duplicate token blocks per theme. Revisit: if analytics-free feedback shows readers on older browsers.
- D-018 (2026-11-10, provisional: made overnight, awaiting owner confirmation). Tongues Serif fixes the optical-size axis at 36 (the h1 size) instead of shipping it. First-paint fonts on / rise from about 80 KB to 132 KB, because our own subsets are less aggressive than Google's pre-made slices. Lighthouse still passes (LCP under 2.5 s on the mobile preset). Why: keeping the axis would add about 110 KB to the first heading's font. Alternatives: keep opsz 20 to 60 (+53 KB); trim OpenType features or the weight range to win back bytes. Revisit: Phase 1 performance review.
- D-019 (2026-11-10, provisional: made overnight, awaiting owner confirmation). Borders policy for every map (code: apps/web/src/canvas/map/policy.ts). (1) Neutral by default: no national viewpoint. (2) Natural Earth breakaway and disputed areas get a neutral hatch and dashed outline above every fill, are never filled by a choropleth and never counted toward any state. (3) A choropleth value reaches a polygon only through its own territory code, never from a neighboring or claiming state. (4) Entities Natural Earth marks as claimed or self-administered get a dashed outline; without their own territory code they are hatched, never filled. (5) Language points are Glottolog coordinates; no point or fill states that a language belongs to a state. (6) Historical borders are labeled approximate. (7) "Borders are approximate and do not imply any position on disputed territory." is always visible on map pages. (8) Viewpoint columns (ADM0_A3_xx) may later power a labeled alternative lens, never the default. Disputed areas are titled by Natural Earth's NAME_EN (for example "Kashmir"), never by the administering state's name. Why: CLAUDE.md rule 7. Open: whether to show self-declared names such as "Donetsk People's Republic" or purely geographic names; whether Natural Earth's TYPE=Disputed without a claim note (Kosovo, Israel) should also get a dashed outline. Revisit: owner review, then Phase 2 historical maps.
- D-020 (2026-11-10, provisional). deck.gl 9.4.1 with MapLibre 6.16: @deck.gl/mapbox reads map.transform, which MapLibre 6 moved. A small getter alias in apps/web/src/canvas/map/controller.ts bridges it. Why: keeps both libraries current. Alternatives: pin MapLibre 5.x. Revisit: remove the alias when deck.gl supports MapLibre 6.
- D-021 (2026-11-10, provisional, NOT MEASURED). Tree renderer, pending D-006: PixiJS. Evidence so far: (1) text: at 12 px PixiJS BitmapText is crisp and legible; deck.gl's SDF TextLayer is thinner and softer at both DPR 1 and 2 (viz-engineer comparison crops); circles look identical. (2) JS: the PixiJS renderer is about 161 KB gzip against about 220 KB for deck.gl, although deck.gl's layers are already loaded by the map, so the saving only applies when the tree loads first. (3) Frame rate and memory: not measured. The headed GPU benchmark (scripts/bench.mjs) was stopped by Claude Code because the development machine ran critically low on memory, and it must not be restarted unattended. Headless software-GL sanity runs are not evidence. Rule from the Phase 0 plan stands: if the measurement shows PixiJS misses a budget that deck.gl meets, switch. Revisit: when the owner runs `pnpm build`, `node scripts/build-territory-index.mjs` and `node scripts/bench.mjs docs/reports/2026-11-10-overnight/bench`.
- D-022 (2026-11-10, provisional: made overnight, awaiting owner confirmation). The Phase 1 app shell follows docs/specs/app-shell.md (ux-designer). Its 20 provisional choices are marked (P) in the spec. The ones with content consequences:
  - Speaker figures are never summed: a lumped macrolanguage shows only figures stated for the macrolanguage itself, and families show no speaker total.
  - Figures whose kind (L1, L2) is not stated stay in their own group, "Kind not stated", and never enter the L1 or total ranges.
  - Macrolanguages get their own route keyed by ISO 639-3 (/macrolanguage/ara, fas, zho), because they have no Glottocode. Lumper/Splitter is per macrolanguage (?lump=fas,zho), split by default, and lives in the Inspector under "Why linguists disagree".
  - The URL is the source of truth. The tree camera is stored relative to the selected node, so links survive layout changes.
  - Single-key shortcuts work only while the canvas has focus (WCAG 2.1.4).
  - The Words tab shows ASJP's own transcription, labeled ASJPcode, and never calls it IPA.
  Why: the nerd contract (provenance, no averaging, contested stays contested) applied to the shell. Revisit: owner review of the spec's open questions.
- D-023 (2026-11-10, provisional: linguist-reviewer recommendation applied overnight, awaiting owner confirmation). Contested scope entries.
  - Key: a contested language gets its Glottolog language-level node as its key for the default view (D-001, D-002), and stays flagged contested, with its candidates and a one-line "why linguists disagree" note. A null key would break pages, search and links; the disagreement lives in the Lumper/Splitter lens and the Inspector. Only rank 91 (Deccan) stays without a key, because Glottolog itself calls the dcc entry spurious.
  - Lumper groups: arabic, chinese, hindustani, punjabi, malay, filipino, kurdish and persian. Each is labeled as either a Glottolog node or the atlas's own grouping.
  - Persian: the default view uses west2369 displayed as "Iranian Persian". The Persian lens groups Iranian Persian, Dari and Tajik and is labeled as the atlas's own grouping ("Persian as one pluricentric language"), because ISO's fas covers only pes and prs. The family fars1254 ("Farsic-Caucasian Tat") is never shown as Persian.
  - Dialect-level chart entries get an anchored section on their parent's page, not their own page.
  - The English display labels for the Glottolog families Farsic, Eastern Farsic and Farsic-Caucasian Tat (D-004) are left for the owner.
  Source: the linguist-reviewer review of content/scope/phase-1-languages.yaml, citing glottolog.org v5.3 pages, Wikidata, the IANA apc record and Wikipedia's ISO 639 macrolanguage article. ISO claims were not verified at SIL, whose site refused automated requests. Revisit: owner review.
- D-024 (2026-11-10, provisional). Country and territory names in the UI come from CLDR 49 (apps/web/src/i18n/regions/, generated by scripts/build-region-names.mjs with the Unicode notice beside them), never from the runtime's Intl.DisplayNames. Why: Node and each browser ship different CLDR versions, so runtime names differed between prerender and browser ("Hong Kong SAR China" against "Hong Kong") and broke hydration on 5 of 409 pages; pinned names also match the source the Inspector cites. Open: CLDR's default names include "Palestinian Territories" and "Falkland Islands"; whether disputed places use CLDR's default, short or variant forms belongs to the borders policy (D-019) and the owner. Revisit: when the pipeline ships region names in data/build.
